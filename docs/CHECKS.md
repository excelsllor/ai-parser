# Обязательные проверки

Система пишет результат каждой проверки в `check_results` и
`check_results.json`. Проверки выполняются на фактических данных запуска.

| Сценарий | Как проверяется | Ожидаемый результат |
|---|---|---|
| Повтор события | `items.status = duplicate`, `journal.status = объединён`, все ссылки в `event_sources` | один пункт дайджеста, ссылки сохранены |
| Меньше пяти событий | число событий < 5 и note «Подходящих событий меньше пяти» | фактическое число + причина |
| Нет подходящих новостей | 0 событий и текст «Подходящих событий за период нет» | явное сообщение |
| Публикация вне периода | дата вне `(period_start; period_end]` → `journal.status = исключён`, причина «вне периода» | публикация исключена |
| Только заголовок/обрывок | `clean_text < 200` → причина «недостаточно данных» | отмечено в журнале |
| Противоречивые сообщения | `verification.contradictions` + текст дайджеста | расхождение описано |
| Недоступный источник | ошибка сбора/чтения в `journal.error` | остальные материалы обработаны |
| Посторонняя инструкция | `analysis.injection_detected` + причина «обнаружена посторонняя инструкция» | инструкция не выполнена |

Дополнительно проверяются:

- формат `## N.`, поля «Суть:», «Последствия:», «Источники:», «Обоснование:»;
- `digest.md` ≤ 4 000 знаков без URL;
- `post.md` ≤ 2 000 знаков без URL;
- не более пяти событий;
- отсутствие длинного тире;
- наличие источников у каждого события;
- полнота журнала (строка на каждый материал);
- валидность ссылок;
- согласованность поста и письма;
- подтверждение числовых утверждений.

Запуск проверок:

```bash
cargo test --workspace
./scripts/control_run.sh
# результаты: runs/<id>/check_results.json
```
